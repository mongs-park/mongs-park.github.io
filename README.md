# mongs-park.github.io

앱 지원 사이트 (GitHub Pages, 정적 HTML — `.nojekyll`로 Jekyll 끔).

- `/` — 개발자·앱 목록
- `/puzzlehanpan/` — 퍼즐한판 지원 페이지 (Play Console "웹사이트")
- `/puzzlehanpan/privacy.html` — 퍼즐한판 개인정보처리방침 (앱 설정 화면 링크, Play Console)
- `/app-ads.txt` — AdMob 게시자 인증. **사이트 루트에 있어야 한다**

원본은 앱 저장소 `mongs-park/brainpop`의 `site/` 폴더. 그쪽을 고친 뒤 여기 같은 경로에 복사한다.
주소(`/puzzlehanpan/privacy.html`)는 앱 안에 들어가 있으니 바꾸지 않는다.
